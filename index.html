# ประเภทบุคลากร (ราชการ) สังกัด/กอง ชื่อ-นามสกุล ตำแหน่งสายงาน เวลาเข้า (เช้า) สถานะเช้า เวลาออก (เย็น) สถานะเย็น เช้า/เย็น (ครั้ง) เช็คสแกนซ้ำ สรุปผลตรวจ เวลาออกเย็น (วันก่อน)

1. สรุปการสแกนแยกตามประเภทบุคลากรตามระบบราชการ

ประเภทบุคลากร ทั้งหมด เข้าเช้า ทันเวลา มาสาย ออกเย็น สแกนซ้ำ ไม่พบสแกน

2. สรุปการสแกนแยกตามสังกัด / สำนัก / กอง

สังกัด / กอง ทั้งหมด เข้าเช้า ทันเวลา มาสาย ออกเย็น สแกนซ้ำ ไม่พบสแกน

รายการข้อมูลสแกนนิ้วดิบทั้งหมดในระบบ และผลตรวจบรรทัดที่สแกนซ้ำ

หากมีชื่อในไฟล์สแกนที่ไม่อยู่ในทะเบียนหลัก ระบบจะเพิ่มเข้าทะเบียนหลักให้อัตโนมัติทันทีและติดป้าย ✨ เพิ่มชื่ออัตโนมัติ
