# ประเภทบุคลากร (ราชการ) สังกัด/กอง ชื่อ-นามสกุล สถานะรายวัน ตำแหน่งสายงาน เวลาเข้า (เช้า) สถานะเช้า เวลาออก (เย็น) สถานะเย็น เช้า/เย็น (ครั้ง) เช็คสแกนซ้ำ สรุปผลตรวจ เวลาออกเย็น (วันก่อน)

รายงานสรุปการมาปฏิบัติงานรายเดือน

รายงานจากประวัติสแกนและสถานะรายวันที่บันทึกไว้ เลือกเดือนเพื่อส่งออก Excel

หมายเหตุ: รายงานจะนับเฉพาะวันที่มีข้อมูลสแกนหรือมีการบันทึกสถานะไว้ในเดือนที่เลือกเท่านั้น และจะไม่สรุปวันที่ไม่มีข้อมูลว่าเป็นวันขาดงานโดยอัตโนมัติ

1. สรุปการสแกนแยกตามประเภทบุคลากรตามระบบราชการ

ประเภทบุคลากร ทั้งหมด เข้าเช้า ทันเวลา มาสาย ออกเย็น สแกนซ้ำ ไม่พบสแกน

2. สรุปการสแกนแยกตามสังกัด / สำนัก / กอง

สังกัด / กอง ทั้งหมด เข้าเช้า ทันเวลา มาสาย ออกเย็น สแกนซ้ำ ไม่พบสแกน

รายการข้อมูลสแกนนิ้วดิบทั้งหมดในระบบ และผลตรวจบรรทัดที่สแกนซ้ำ

หากมีชื่อในไฟล์สแกนที่ไม่อยู่ในทะเบียนหลัก ระบบจะเพิ่มเข้าทะเบียนหลักให้อัตโนมัติทันทีและติดป้าย ✨ เพิ่มชื่ออัตโนมัติ

# ประเภทในไฟล์ดิบ ชื่อในไฟล์ดิบ วัน/เวลาสแกน วันที่ เวลา ช่วงเวลา ประเภทตามระบบราชการ สังกัด/กอง ครั้งที่ในกะ ผลตรวจสแกนซ้ำ

➕ เพิ่มรายชื่อบุคลากรด้วยตนเอง (นอกเหนือจากการเพิ่มอัตโนมัติเมื่อแนบไฟล์)

ปกติเมื่อแนบไฟล์สแกนนิ้ว ระบบจะเช็คและเพิ่มคนที่ยังไม่มีในรายชื่อให้อัตโนมัติอยู่แล้ว แต่สามารถเพิ่มล่วงหน้าหรือแก้ไขสังกัด/ตำแหน่งในตารางด้านล่างได้ตลอดเวลา
